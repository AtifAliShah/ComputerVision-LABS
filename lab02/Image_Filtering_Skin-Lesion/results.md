# Lab 02 — Effect of Image Filtering on Skin-Lesion Classification

## Objective

This laboratory investigates how spatial-domain image filters affect skin-lesion classification performance using pretrained deep-learning models on the HAM10000 dataset. The goal is to determine whether classical image-processing filters improve, degrade, or have no significant effect on model performance when applied as a preprocessing step before feeding images into a CNN.

## Models

Based on the results of Lab Activity 1, the following three pretrained CNN models were selected for this experiment:

- **EfficientNet-B0**
- **ResNet50**
- **DenseNet121**

Each model was fine-tuned using transfer learning, with the final classification layer replaced to match the number of lesion classes in HAM10000.

## Filters

Six preprocessing conditions were compared for every model:

| Filter | Description |
|---|---|
| No Filter | Original, unfiltered image |
| Average | Mean/box blur (5x5 kernel) |
| Gaussian | Gaussian blur (5x5 kernel) |
| Median | Median blur (5x5 kernel) |
| Sharpening | Custom sharpening convolution kernel |
| Sobel | Sobel edge-detection filter |

## Dataset

The experiments use the **HAM10000** skin-lesion dataset, containing 10,015 dermatoscopic images across seven lesion classes:

| Code | Class Name |
|---|---|
| akiec | Actinic Keratoses |
| bcc | Basal Cell Carcinoma |
| bkl | Benign Keratosis |
| df | Dermatofibroma |
| mel | Melanoma |
| nv | Melanocytic Nevi |
| vasc | Vascular Lesions |

The dataset was split into training, validation, and testing subsets (80% / 10% / 10%) using a stratified split. The **same split** was used for every experiment to keep comparisons fair.

## Evaluation Metrics

Each experiment was evaluated using:

- Accuracy
- Precision (weighted)
- Recall (weighted)
- F1-score (weighted)
- Macro-F1
- Balanced Accuracy
- AUC (macro, one-vs-rest)

Confusion matrices, training/validation accuracy curves, training/validation loss curves, and per-class performance were also generated for every experiment.

## Experimental Design

There are:

**3 models × 6 filter conditions = 18 experiments**

The dataset split, preprocessing steps, optimizer (Adam), learning rate (0.0001), batch size (32), number of epochs (5), and evaluation procedure were kept identical across all 18 experiments to ensure a fair, controlled comparison.

## Discussion

**Q1. Which three pretrained models performed best in Lab Activity 1?**
The three pretrained models selected for this experiment were EfficientNet-B0, ResNet50, and DenseNet121, based on their performance in Lab Activity 1.

**Q2. How does filtering affect each of the three models?**
Image filtering affects each pretrained model differently. Smoothing filters such as Average, Gaussian, and Median reduce image noise and fine detail, while Sharpening enhances local edges and Sobel emphasizes boundaries. The effect on performance therefore depends on which visual features each model relies on for classification.

**Q3. Which filter produces the greatest change compared with the unfiltered baseline?**
Determined from the `Absolute Macro-F1 Change` column generated in the notebook once all experiments complete. The filter with the highest absolute change is the answer.

**Q4. Does the effect of a filter remain consistent across all three models?**
No. The same filter can affect different architectures differently. Since each model learns different internal feature representations, a filter that improves one model's performance may have little effect on, or even reduce, another model's performance.

**Q5. Does filtering improve or decrease Macro-F1 and Balanced Accuracy?**
Determined from the actual results table. Conceptually: filtering can either improve or decrease Macro-F1 and Balanced Accuracy depending on whether it removes irrelevant noise (helps) or removes useful lesion information (hurts).

**Q6. Which lesion classes are most affected by filtering?**
Determined from the per-class results (`Lab02_Per_Class_Results.csv`) — the class with the largest F1-score change across filters is the most affected.

**Q7. Why might smoothing remove useful lesion texture or morphological information?**
Smoothing filters reduce high-frequency variations in an image. Skin lesions contain important diagnostic features such as borders, pigmentation patterns, and fine textures. Excessive smoothing can blur or remove these features, making classification more difficult.

**Q8. Why might sharpening or edge detection help or hurt classification?**
Sharpening can enhance lesion boundaries and structural detail, which may help a model identify important morphological features. However, excessive sharpening can amplify noise. Sobel filtering emphasizes edges but discards most color and texture information, so it may help when boundaries matter most but hurt when color/texture are more diagnostically important.

**Q9. What is the difference between convolution and correlation?**
Correlation slides a kernel over an image without flipping it. Convolution flips the kernel both horizontally and vertically before sliding it over the image. In deep learning frameworks, the operation commonly referred to as "convolution" is technically implemented as cross-correlation.

**Q10. Relationship between classical image processing and deep learning?**
Classical image processing applies predefined transformations (smoothing, sharpening, edge detection) before feature extraction, while deep learning automatically learns useful features directly from raw images through convolutional layers. Filtering acts as a preprocessing step that changes the information available to the CNN — this experiment tests whether manually engineered transformations complement or interfere with the features the network learns on its own.
